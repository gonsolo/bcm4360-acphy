# Status 2026-09-26 (evening)

## What works on real hardware (MacBookAir6,1, BCM4360, AC-PHY rev 1, radio 2069 rev 4)

- Attach, firmware (ucode42 + initvals extracted from wl.ko), DMA with
  buffers below 4 GB (`dma32=1`).
- Receive: monitor mode decodes ~80% of the router's beacons on channel 1,
  CCK and OFDM, with `ac_replay=1 ac_por=63` (wl's channel-6 ifup state
  plus wl's first-load state, then our own VCO cal / channel tuning).
- AC RX header parsing, AC TX descriptor (4-byte passthrough prefix +
  124-byte descriptor), AC TX status (2x4 words), rev-40 FIFO init,
  address match table (AMT entries 63/62), SHM chanspec, ACK/CTS PHY
  control word (SHM 0x22 = 0x0040), wl's per-core RF control overrides.
- Transmit: host frames go out cleanly at 1-24 Mb/s (TX quality matrix),
  no PHY TX errors for CCK or OFDM.
- Scan, open-system authentication and association with the home router.

## What doesn't

- The firmware's own ACKs: every ACK attempt raises a PHY TX error and
  nothing reaches the router, which then retries every frame 7 times.
  WPA2's 4-way handshake therefore fails.
- Other channels only work after wl's state has been applied once on
  channel 6; the replay is diagnostic scaffolding, not real init code.
- 5 GHz is not implemented.

## Ruled out for the ACK failure

SHM 0x22 core mask, wl's MAC timing registers (trace-visible and the
61 live-dump differences, `traces/macdump-*`), template RAM address block,
per-rate SHM words (firmware maintained), scratch memory (backoff/retry),
RF sequencer table (matches except two unwritable entries), PHY tables
(all 3022 entries match), PHY registers wl writes (match).

## Test harness and safety

- `tools/postboot.sh` after every reboot: runtime udev override (NixOS
  restarts wpa_supplicant on every WiFi interface add/remove, which drops
  the USB stick link) and the ping watchdog `tools/netwatch.sh`.
- `b43_live.sh swap|load|unload`, `tools/ack_setup.sh`, `tools/acktest.sh`
  (iw auth; router replies counted on b43's own monitor vif `b43mon`).
- Never add monitor interfaces to the USB stick; it drops its connection.
- Never rebind wl after b43 touched the chip; reboot instead.
